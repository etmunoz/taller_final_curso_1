### Entorno virtual e instalación

```
Crea el entorno virtual .venv con python3 -m venv .venv, instala requirements.txt dentro de ese entorno
(.venv/bin/pip install -r requirements.txt) y al terminar pégame la salida de .venv/bin/python --version y de
.venv/bin/pip list filtrada por langchain, langgraph, redis, mcp y fastembed. No instales nada fuera de .venv.
Si falla la instalación de algún paquete, muéstrame el error completo y no sigas.
```
